## Open-source statement

MeowKit-S3 firmware is open for learning, development, and community contribution. You are welcome to study the source code, report issues, improve existing features, and build new applications for MeowKit.

Third-party libraries and components remain subject to their respective licenses. Please use security-related features only on devices you own or are authorized to test.

## Become a contributor

We welcome practical ideas, clear bug reports, documentation improvements, and well-tested pull requests.

Active contributors may be eligible to receive a MeowKit device for development and testing. Tell us about yourself, your proposed contribution, and links to relevant work:
